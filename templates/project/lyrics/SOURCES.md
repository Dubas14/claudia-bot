# References in the lyrics - sources

Every reference in the lyrics (a meme, a fact, a name, a number, a quote) gets a row here with its source. These are
the jokes the explaining graphics must land: the storyboard gives each one its graphic (docs/40-storyboard). Check
every fact before it goes into a lyric. Real people appear only as objects (a badge, a post, the paperwork), never as
a generated face.

Status: V = verified by two sources, V1 = one primary source, FIX = the wording must change before it is sung or
shown, KEEP = the owner keeps it knowingly (say why), - = no factual claim.
