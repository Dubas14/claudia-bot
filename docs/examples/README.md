# Examples: verbatim exemplars from the two reference videos

Few-shot material for the bot and for delegated agents: real prompts, packs, records and reviews from *Escape Velocity*
(EV) and *Clodyssey (Superpersuasion)* (SP), scrubbed of the creator's identity, private codes, hosts and job ids. Each
exemplar carries a one-line note on why it worked. **Copy the structure, not the words**: replace the lead canon, the
song, the world and the jokes with the user's own.

| File | What | Use it when |
|---|---|---|
| [`suno-packs.md`](suno-packs.md) | both songs' Style, Exclude, settings, section cues and lyrics fields | writing the user's Suno pack (`10-song.md`) |
| [`mj-prompts.md`](mj-prompts.md) | canon blocks, per-chapter style tails, and plate prompts by framing (ECU → EWS, two-shots, matched pairs, a character reference, "make the feature the subject"), plus what bad looks like | writing the plate prompt book (`50-plates-midjourney.md`) |
| [`seedance-prompts.md`](seedance-prompts.md) | EV sung, cover and motion prompts; SP screenplay prompts (windows, motion, a 3D previz move) with the book header and the eight-part grammar; moderation-safe rewordings; round-1 failures | writing the video prompt book (`60-clips.md`, `61-lipsync.md`) |
| [`image-edit.md`](image-edit.md) | the fixed "keep everything else" clause and ten real edit instructions | fixing a plate's canon break at the source (`51-plates-api.md`) |
| [`shots-json.md`](shots-json.md) + [`shots.example.json`](shots.example.json) | EV's and SP's original shot records and five shots in the toolkit's `board/shots.json` contract (structured `type[]` and `devices[]`) | writing or auditing the storyboard (`40-storyboard.md`) |
| [`production-skeleton.md`](production-skeleton.md) | the binding plan (`PRODUCTION.md`) skeleton with real caps, the stage/owner/gate table, file contracts, the run log, an UPDATE block | before any parallel or delegated work (`95-delegation.md`) |
| [`review.md`](review.md) + [`review-pass.json`](review-pass.json) + [`review-fail.json`](review-fail.json) + [`review-toolkit-form.json`](review-toolkit-form.json) | two real chapter reviews (pass and fail) and the failing one in the toolkit's reviewer schema, clip-QA lines, a safety-scan findings file, the owner's one-line review notes | reviewing chapters, takes and releases (`80-review-qa.md`) |

Records, not material: the prompts keep each film's own age words ("young", "in her mid-twenties"), which the canon
has retired (claudia.gallery: Claudia is in her late twenties, never "young"); new prompts use today's identity text.
The films' songs, lyrics and stems are never re-released; a project that runs the toolkit on one of them is the
owner's private test only. Release your own song.

Scrub notes: the creator is credited only as **anabology**; their personal Midjourney profile code, job ids, hostnames
and workflow run ids are removed; quotes are verbatim (typos kept); a few long passages are elided with "…". Real people
appear only where the published making-of had them (lyrics quoting public figures are omitted from `suno-packs.md`).
